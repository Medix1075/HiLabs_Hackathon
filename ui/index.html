CHALLENGE C7 BENCHMARK ENGINE

Provider Peer Group Benchmark & Price Dispersion Curve

Hierarchical Back-off Matching

Quantitative Defense of Cost-Effectiveness Metrics

1. Peer Definition ("Similar Providers")

Providers are strictly grouped by (Specialty × Region × NPI Type). A hierarchic back-off model gracefully cascades to statewide specialty if fewer than 5 peer providers exist in the MSA.

2. Empirical-Bayes Shrinkage

Volume-weighted geometric mean of (Rate / Peer Median) shrunk towards market index 1.0 using formula: log_index × n_eff / (n_eff + 2.0), guarding against single-code volatility.

3. Tiers & Arbitrage Strategy

Providers scored into 5 defensible tiers. Contracting teams prioritize renegotiation for Tier 5 (> 1.20x median) where identical quality care is available in the same zip code at median rates.

Priority 1 Rate File Network Name Deep streaming inspection of provider_references[].network_name. Direct payer contract label. Health Net CA left blank in all 2,825 groups, triggering Phase 2 plan vote.
Priority 2 File Vote (≥ 80% Threshold) Aggregates plan classes pointing to shared rate files. Files with ≥ 80% non-PPO plans classified as non-PPO. A plan never votes for itself.
Priority 3 Whole-Word Keyword Matching Regex whole-word matching (\bPPO\b, \bHMO\b, \bEPO\b, \bPOS\b, \bEOA\b). Prevents "POST DOC" matching POS; separates HMO product prefixes (SmartCare, Salud, WholeCare).
Priority 4 Conflict Resolution Contradictory tokens (e.g. PPO CA IRONWORKERS FWP-EPO$10). Specific excluded product option (EPO) overrides general PPO prefix → Ruled OUT as non-PPO.
