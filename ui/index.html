Network status of NPI + TIN pairs (C4)

What do these statuses mean?
CONFIRMED_PPO
Direct PPO evidence for this NPI + TIN, such as a Health Net PPO directory listing. Only these rows go into deliverable 1.
PPO_CANDIDATE
Weak or inferred PPO evidence (TIN-only or name + ZIP match, sister NPI listed). Kept in the candidate file.
UNRESOLVED
No evidence either way. Kept in the candidate file.
CONFIRMED_NON_PPO
Evidence it is not PPO (capitation, non-PPO listing). Dropped from both files.

C4 decides the status per NPI + TIN pair, not per provider reference, because one reference can mix PPO and non-PPO doctors.
